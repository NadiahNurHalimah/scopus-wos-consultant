# Scientia Advantage

Aplikasi konsultasi publikasi ilmiah (Scopus dan Web of Science).

- `backend/`: API Node.js + Express + MySQL (sudah berisi pendaftaran, login, dan profil)
- `web/`: React (Vite) + Tailwind, dibuat pada tahap berikutnya

Panduan menjalankan backend ada di `backend/README.md`.
